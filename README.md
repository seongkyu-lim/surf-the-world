# 세상 읽기 · Surf the World

매일 아침 Claude가 경제·정치·생활·국제 뉴스를 찾아 읽고, 5분 분량의 브리핑을 써서 올리는 사이트.

**사이트: https://seongkyu-lim.github.io/surf-the-world/**

기술 뉴스만 보던 개발자가 금리, 집, 세금, 정책 같은 세상 돌아가는 일을 꾸준히 따라가려고 만들었다. 사람이 손으로 올리는 단계는 없다.

## 브리핑 구성

- **지표 한눈에**: 한·미 기준금리, 환율, 증시, 유가
- **오늘의 핵심 3~5건**: 무슨 일인지, 왜 중요한지, 생활에 어떤 영향이 있는지
- **후속 추적**: 이전에 다룬 이슈의 진행 상황
- **요일 코너**: 월 재테크 기초 · 화 가정·생활 · 수 국제 · 목 산업·기술 · 금 정책·법안 · 토 교양 · 일 주간 정리
- **오늘의 용어**: 하루 하나씩 용어집에 누적

## 같은 걸 만들고 싶다면

작성 규칙과 프롬프트, 구축 과정을 전부 공개해 두었다. 관심 분야만 바꾸면 자기만의 브리핑 사이트가 된다.

## 유의 사항

- AI가 공개 기사와 통계를 요약한 자료다. 오류가 있을 수 있으니 중요한 판단 전에는 출처 링크의 원문을 확인한다.
- 재테크 내용은 개념과 제도 설명이며 투자 권유가 아니다.
- 기사 본문은 옮기지 않고 요약과 링크만 싣는다.
